# Rice Seedling Phenotype Quantifier

水稻秧苗图像表型量化与数据管理软件 V1.0

## 一、项目简介

这是一个面向水稻育秧图像分析的 Windows 桌面工具，用于处理普通二维图像中的水稻秧苗绿色区域，可完成尺度换算、表型指标计算、历史数据管理、批量分析和报告导出。

核心处理采用传统图像处理方法，分析过程在本地完成。软件不依赖深度学习模型训练，不调用云端服务或外部智能接口，也不包含生成式人工智能服务、三维重建和农学诊断功能。

可用于水稻秧苗图像表型数据记录、教学演示、科研辅助整理和批量统计分析。

---

## 二、功能特点

### 1. 单张图像分析

在单张图像分析页面，可以导入并预览 JPG、JPEG、PNG 或 BMP 图像。软件提供 HSV、ExG 和 HSV+ExG 三种绿色区域分割方法，分割后会同时显示掩膜图和叠加结果图。设置好比例尺后即可计算水稻秧苗的二维表型指标，结果既可以保存到历史记录，也可以导出为 Word 图文报告。页面还会给出简要的结果提示，方便对照图像进行复核。

### 2. 表型指标计算

软件根据二维图像的分割结果和比例尺换算，计算株高估算、冠幅估算、投影面积和绿色覆盖率，同时统计 ExG 叶色指数均值、Green Ratio 与外接矩形填充率。在这些结果的基础上，软件还会给出一个内部长势评分，用于同批样本之间的对照。

### 3. 历史记录管理

分析记录保存在本地 SQLite 数据库中。进入历史记录页面后，可以查询已有记录、查看统计摘要，也可以打开某一条记录，回看它的指标、备注、复核提示以及原图、掩膜图和叠加图。备注可以随时修改，不再需要的记录也可以删除。表格中的序号会保持连续，数据库内部的记录 ID 则继续保留，用于数据追踪。需要进一步整理时，可将历史记录导出为 Excel 或 CSV。

### 4. 批量分析

需要处理多张图像时，可以直接选择一个文件夹，软件会读取其中的 JPG、JPEG、PNG 和 BMP 文件，依次完成绿色区域分割与表型指标计算。处理过程中会显示总体进度，以及每张图像的成功或失败状态。分析结束后，可以查看统计摘要、可视化图表和结果提示，也可以选中某个样本，单独核对它的原图、掩膜图、叠加图和指标结果。成功记录可按需保存到历史记录，整批结果则可以导出为 Excel 或 CSV。

### 5. 参数设置

参数设置页面集中管理分割方法、HSV / ExG 阈值、最小连通域面积、形态学核大小和默认比例尺。调整后的参数可以保存，也可以恢复为默认值；单图分析和批量分析都会读取这里保存的设置。

### 6. 结果解释与样本复核

单图分析和批量分析都会生成结果提示。在批量结果或历史记录中，还可以打开复核窗口，把原图、掩膜图和叠加结果图放在一起查看，再结合表型指标与内部评分进行人工判断。

说明：结果解释和复核提示仅基于二维图像指标和软件内部评分生成，用于辅助查看和结果复核，不作为农学诊断、病害判断、品种评价或生产决策依据。

## 三、技术边界说明

处理流程包括颜色空间转换、阈值分割、形态学处理、连通域过滤、像素统计和比例尺换算。

这套处理不涉及深度学习模型训练或神经网络推理，也不包含生成式人工智能服务，不会调用云端 AI 接口或外部大模型接口。软件处理的是普通二维图像，不进行三维点云重建和三维模型生成。它给出的结果是图像表型量化数据，不提供病虫害诊断、氮素含量预测或田间生产决策建议。

## 五、安装方法

### 1. 克隆项目

```bash
git clone https://github.com/KaifengWei/rice-seedling-phenotype-quantifier.git
cd rice-seedling-phenotype-quantifier
```

### 2. 创建虚拟环境

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

如果系统中存在多个 Python 版本，建议使用 Python 3.11：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. 安装依赖

```powershell
python -m pip install -r requirements.txt
```

若网络环境不稳定，可根据实际网络情况选择合适的 PyPI 镜像源。

## 七、使用流程

### 1. 单图分析流程

```text
导入图像
↓
执行分割
↓
计算指标
↓
保存记录 / 导出报告
```

页面中的按钮会随着分析进度依次启用。导入图像后才能执行分割，完成分割后才能计算指标。指标计算完成后，可以保存记录或导出报告，同一轮结果各允许操作一次；重新导入图像或重新计算，就会进入新一轮分析。

### 2. 批量分析流程

```text
选择文件夹
↓
读取参数
↓
开始批量分析
↓
查看统计摘要
↓
查看结果解释提示
↓
查看可视化图表
↓
复核选中样本
↓
保存成功记录 / 导出 Excel / CSV
```

批量分析会读取“参数设置”页面中保存的分割参数，并对整批图像使用统一比例尺。每张图像都会显示处理状态，失败时同时给出原因。分析完成后，页面会生成统计摘要、柱状图和评分等级统计；选中某条样本，还可以继续查看原图、掩膜图、叠加图、指标和复核提示。

成功记录可以手动保存到历史记录。失败记录不会写入数据库，但仍会留在批量结果表格和导出文件中，便于后续检查。整批结果可导出为 Excel 或 CSV。

### 3. 历史记录流程

```text
保存单图记录 / 保存批量成功记录
↓
进入历史记录页面
↓
查询 / 查看详情 / 编辑备注 / 删除
↓
导出 Excel / CSV
```

历史记录表格第一列使用连续序号，删除记录后会自动重新排列。数据库内部的记录 ID 不受影响，只用于数据追踪。删除一条数据库记录不会同时删除原始图像、掩膜图或叠加图文件。除了页面上的统计摘要，还可以打开选中记录，查看对应图像、指标、备注和复核提示。

## 八、指标说明

### 1. 株高估算

株高估算基于分割掩膜区域的外接矩形高度计算：

```text
株高估算值 = 掩膜外接矩形高度像素数 × cm_per_pixel
```

该指标为二维图像中的可见高度估算值，不等同于真实三维植株高度。

### 2. 冠幅估算

冠幅估算基于分割掩膜区域的外接矩形宽度计算：

```text
冠幅估算值 = 掩膜外接矩形宽度像素数 × cm_per_pixel
```

### 3. 投影面积

投影面积基于绿色掩膜像素数量计算：

```text
投影面积 = 掩膜像素数 × cm_per_pixel²
```

### 4. 绿色覆盖率

绿色覆盖率表示绿色掩膜区域在有效图像区域中的占比：

```text
绿色覆盖率 = 绿色掩膜像素数 / 有效图像区域像素数
```

### 5. ExG 叶色指数

ExG 绿色增强指数计算公式为：

```text
ExG = 2G - R - B
```

软件统计掩膜区域内的 ExG 均值作为图像叶色相关指标。

### 6. Green Ratio

Green Ratio 计算公式为：

```text
Green Ratio = G / (R + G + B)
```

软件统计掩膜区域内的 Green Ratio 均值。

### 7. 外接矩形填充率

外接矩形填充率用于描述掩膜区域在外接矩形中的填充程度：

```text
外接矩形填充率 = 掩膜像素数 / 外接矩形面积
```

### 8. 长势评分

长势评分为软件内部综合评分，基于绿色覆盖率、Green Ratio 和外接矩形填充率计算。

该评分仅用于同批次样本之间的相对比较，不作为农学诊断、病害判断或生产决策依据。

## 九、参数说明

软件支持以下参数设置：

| 参数           | 说明                              |
| -------------- | --------------------------------- |
| 分割方法       | 支持 HSV、ExG、HSV+ExG            |
| HSV 下限       | 绿色区域提取的 HSV 下限           |
| HSV 上限       | 绿色区域提取的 HSV 上限           |
| ExG 阈值       | ExG 分割中的二值化阈值            |
| 最小连通域面积 | 用于过滤小噪声区域                |
| 形态学核大小   | 用于开运算、闭运算等掩膜后处理    |
| 默认比例尺     | 默认 cm/pixel，用于像素到厘米换算 |

参数保存后会写入本地配置文件，并被单图分析和批量分析读取。

## 十、导出说明

### 1. Word 报告

单图分析完成后，可以导出 Word 图文报告。报告会记录生成时间、软件版本、样本名称、原始图像路径和本次使用的分割参数，并附上原图、分割掩膜图、叠加结果图与表型指标表。文档末尾还会保留结果说明和免责声明。

### 2. Excel / CSV 导出

历史记录和批量分析结果均可导出为 Excel 或 CSV 文件。

Excel 文件包含明细数据和统计摘要两个工作表。

CSV 文件保持为明细数据，便于兼容普通表格工具。

导出内容保留序号、样本名称、图像路径、分析时间、分割参数和比例尺，也包含株高估算、冠幅估算、投影面积、绿色覆盖率、ExG、Green Ratio、长势评分、备注及软件版本。

CSV 文件采用 UTF-8 with BOM 编码，便于在 Excel 中打开中文字段。
